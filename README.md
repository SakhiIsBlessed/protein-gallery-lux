# Protein Gallery Luxe

Build a modern, premium, award-winning ecommerce website for a brand called "Protein Gallery".

The website should NOT look like a typical ecommerce template. It should feel like a luxury fitness brand with cinematic animations, premium typography, smooth scrolling, and immersive interactions similar to Apple, Nike, Awwwards, Porsche, and the reference animation.

The entire website should use a dark luxury theme.

=========================================

DESIGN STYLE

=========================================

Theme:

- Matte Black (#0B0B0B)

- Dark Gray (#161616)

- White (#FFFFFF)

- Orange Accent (#FF6B00)

- Gold Accent (#FFC857)

Typography:

- Headings: Bebas Neue

- Secondary: Space Grotesk

- Body: Inter

The design must have:

- Large spacing

- Minimal UI

- Luxury aesthetics

- Rounded corners

- Glassmorphism

- Soft shadows

- Premium lighting

- High-end feel
